# PowerSchool Report Card Tool

![Screenshot of home view](screenshots.png)

Try the app is currently deployed on [Github pages](https://jmuspratt.github.io/power-school-reporter-react/)

- This is a fork of code by [Steve Berczuk](https://github.com/sberczuk/power-school-reporter-react)
- The data is processed _entirely in the browser_ on your device.
- The layout assumes that the marking periods are labeled as 'Terms' (T1, T2, T3, Y1) or 'Quarters' (Q1, Q2, Q3, Q4, Y1)
